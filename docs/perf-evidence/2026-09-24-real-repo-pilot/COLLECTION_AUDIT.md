## Runtime evidence and limits

- All twelve Rust grading records identify Rust 1.96.0. Both prepared Cargo homes
  contain only a registry cache, without credentials, configuration or Git
  checkout caches. The frozen launcher clones a private Cargo home per arm and
  ignores global Git configuration.
- All six platform grading records identify Node 26.5.1, Vitest 4.1.5 and MSW 2.13.5.
  Their prepared runtime-lock hashes match. These installed dependencies differ
  from the historical source lockfile. The frozen launcher prevents pnpm from
  automatically replacing or reinstalling that prepared environment.
- All six Python grading records attest to standard-library dependencies,
  execution of the real handler/service, no development conftest, a cleared
  environment and denied network/subprocess access. Python 3.14.6 and pnpm
  11.3.0 are recorded in the collection manifest; Python has no separate
  per-trial interpreter-version field.
- Binary hashes are recorded at collection start, not re-attested in every
  trial. No complete dependency-tree digest was collected. Equivalent cache
  preparation follows the frozen runner; this audit does not independently
  prove every installed dependency byte was identical at execution time.
- Provider prompt caching remained enabled and was not reset. The aborted
  pre-matrix Off attempt may have warmed the r01 prefix. Alternating arm order
  does not remove this limitation. Cache reads/writes must remain distinct,
  and CLI cost estimates do not establish subscription cash charges.
- This is a single-agent, source-only diagnostic pilot with three completed
  repetitions per task and arm. It does not test accumulated engineering memory, cross-repository
  expertise or MCP retrieval. Historical replay also cannot exclude knowledge
  already present in the coding model.

The audit used saved records, traces, settings, grades, fixture metadata and
databases. It launched no coding agents, models, graders or builds, inspected no
active candidate, and changed no collection evidence or canonical database.
