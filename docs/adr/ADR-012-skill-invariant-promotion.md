# ADR-012: Skill and invariant promotion

- Status: accepted
- Date: 2026-08-28

## Decision

Represent V1 procedures, skills, and invariants as typed memories so they inherit evidence,
bitemporal validity, utility, scope, purge, and retrieval guarantees. Distillation requires a
successful source task and Tier A/B evidence, begins as candidate, and exact duplicates add
provenance rather than copies. Conservative promotion remains manual/evidence-gated; blocking policy
is opt-in and outside the default V1 path.
