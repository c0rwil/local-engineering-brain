Phone-task termination currently reports system cancellation as a human stop. Use superseded when a new task replaces an active task, cancelled_by_caller for an MCP cancellation or session end, and device_ended when the device ends the session. Keep stopped_by_user for an explicit human stop. Make terminal state and error code agree, preserve remote cancellation, and keep the existing narrower set of terminal values that phones are allowed to submit. Add regression coverage.
