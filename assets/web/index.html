This page is generated from the live code graph — it cannot go stale. To work with the brain from a terminal or agent:

  1. See what the brain knows about a task: leb context "<task>" --path <repo> prints the exact context it would inject, with a why for every item.
  2. Code with injected memory: launch claude-mtplx (Claude Code through the LEB proxy) — validated lessons, team standards, and linked-repo knowledge inject automatically. The leb MCP server adds recall, impact, and outcome tools.
  3. Teach it: after finishing real work, leb learn "<lesson>" --task … --evidence …; only evidence-backed lessons ever inject. Record deployment facts with leb fact set.
  4. Keep everything fresh: the refresh buttons below index fetched origin/main (shared truth — your checkout is never touched); tick “from local checkout” or run plain leb index to see your branch instead. Agent context always follows the local tree you are editing.
